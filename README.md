# StudyFlow – Smart Study Planner

## About the Project
StudyFlow is a smart and user-friendly study planner website designed to help students manage their study time effectively. It helps students organize daily tasks, schedule study sessions, track their progress, and improve concentration.

## Features
- **Dashboard:** View daily study activities and progress.
- **Add Tasks:** Add, manage, and complete study tasks.
- **Study Sessions:** Plan study sessions according to subjects and time.
- **Focus Timer:** Use a timer to improve concentration.
- **Progress Tracking:** Monitor completed tasks and learning progress.
- **User-Friendly Design:** Simple and responsive interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run the Project
1. Clone this repository:
      https://github.com/skkousar375-eng/Studyflow-smart-study-planner
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Run the website using the Live Server extension or your browser.

## Project Objective
The main objective of StudyFlow is to help students develop better study habits, manage time efficiently, reduce distractions, and achieve their academic goals.

StudyFlow brings essential study-planning tools together in one platform, making learning more organized, focused, and productive.
